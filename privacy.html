隐私政策

最后更新：2026 年 10 月

本政策适用于「Google Workspace 个人助手」（下称"本工具"）。 本工具是一个仅供开发者本人使用的本地程序，不面向公众提供服务， 也不允许任何第三方注册或授权使用。

1. 访问哪些 Google 用户数据

经账号持有人明确授权后，本工具会通过 Google 官方 API 访问以下数据：

  • Gmail：读取邮件、发送邮件、修改标签、管理过滤器
  • Google 日历：读取日历与日程、创建和修改日程
  • Google 云端硬盘：读取文件列表与内容、查看权限

访问范围严格限于上述已授权的权限，且仅针对授权账号本人的数据。

2. 如何使用这些数据

数据仅用于开发者本人的个人事务管理，包括：整理与检索自己的邮件、管理自己的日程、 查看与整理自己的云端硬盘文件。数据不会被用于广告、画像、训练模型或任何其他用途。

3. 存储与传输

  • OAuth 授权令牌仅保存在开发者本人电脑的本地文件中。
  • 本工具不运营任何服务器，不将任何数据上传至第三方。
  • 所有 API 请求由本机直接发往 Google 官方接口，不经过任何中间方。

4. 共享与披露

本工具不会向任何第三方出售、出租、共享或披露 Google 用户数据。 不存在数据分析、广告或追踪组件。

5. 保留与删除

本工具不在本地长期保存邮件或日历内容。授权令牌可随时撤销： 访问 Google 账号权限页面，移除本工具的访问权限即可立即失效。

6. 数据使用限制声明

本工具对 Google API 所返回数据的访问与使用，遵守 Google API Services User Data Policy，包括其中的 Limited Use（有限使用）要求。
